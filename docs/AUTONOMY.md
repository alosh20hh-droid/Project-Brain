# الاستقلالية

العقل يعمل بدورات قصيرة قابلة للاستئناف، وليس كطلب طويل بلا حدود.

في كل دورة:
1. يقرأ الحالة الدائمة.
2. يركز على أخطر مجهول.
3. يختار تجربة قليلة الكلفة.
4. يحدد الدليل قبل التنفيذ.
5. ينفذ عبر منفذ محدود.
6. يطلب تحققاً مستقلاً.
7. يتعلم من النتيجة.
8. يحفظ نقطة استئناف.
9. يعيد التخطيط عند ظهور مانع أو فشل متكرر أو نتيجة غير مثبتة.

حدود الاستقلالية:
- لا دفع أو عقد أو حذف غير قابل للتراجع بلا موافقة المالك.
- لا يعتبر كلام المنفذ دليلاً كافياً.
- لا يعيد المحاولة بنفس الطريقة بلا نهاية.
