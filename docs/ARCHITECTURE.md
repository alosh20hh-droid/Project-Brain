# البنية

التحكم بالمشروع يكون أعلى من العقل، والعقل أعلى من التنفيذ.

Paperclip (لاحقاً) -> محول التحكم -> العقل -> طلب تنفيذ مضبوط -> موجه التنفيذ -> UFO أو منفذ آخر -> أدلة -> متحقق مستقل -> تحديث حالة المشروع.

## الحدود
- Nous: التفكير والذاكرة، ولا يملك صلاحية النجاح الذاتي.
- Paperclip: حالة المشروع والمهام والموافقات والميزانية.
- UFO: منفذ خارجي محدود، وليس مدير المشروع.
- Verifier: مستقل عن المنفذ.

## قاعدة الدمج
لا ننسخ كود المشاريع الأصلية داخل هذا المستودع. نربطها بمحولات واضحة حتى يمكن تحديث كل مشروع بصورة مستقلة.
