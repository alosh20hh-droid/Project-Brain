# التشغيل المتكامل

المشغل المركزي يجمع دورة العقل مع التخزين الدائم وسجل التشغيل والأحداث ومراقبة الصحة.

المسار:
الهدف → حالة المشروع → التخطيط → طلب تنفيذ محدود → الموافقات → المنفذ → الأدلة → التحقق المستقل → التعلم → حفظ الحالة → الدورة التالية.

بعد كل دورة تحفظ الحالة برقم إصدار وتحفظ نقطة تشغيل. لذلك يمكن لعملية جديدة فتح قاعدة البيانات نفسها واستعادة المشروع.

هذا الاختبار لا يدعي أن التكاملات الخارجية جاهزة بعد. هو يثبت أن قلب النظام يستطيع المرور بدورة كاملة وحفظها واستعادتها. التكامل مع مزود نموذج حقيقي ومنفذات حقيقية يبقى عبر الحدود المعرفة مسبقاً.
