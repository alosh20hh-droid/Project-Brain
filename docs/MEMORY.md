# الذاكرة طويلة المدى

الذاكرة ليست نص المحادثة. هي معرفة منظمة مرتبطة بالمشروع.

تحفظ:
- الحقائق المثبتة.
- القرارات وأسبابها.
- الدروس من النجاح والفشل.
- مراجع الأدلة.
- درجة الثقة.
- المعلومة الجديدة التي تستبدل معلومة قديمة.

قبل التخطيط يبني النظام سياقاً صغيراً من الحالة الحالية والذكريات الأكثر صلة، بدلاً من إرسال التاريخ كله للنموذج.

يوجد أيضاً بصمة للعمل المنجز حتى لا يعيد النظام نفس البحث أو المهمة بلا سبب.

الذاكرة لا تمنح صلاحيات تنفيذ، ولا تعتبر الذكرى القديمة حقيقة إذا استبدلت بدليل أحدث.
