# الحالة الدائمة والاستئناف

الحالة المهمة لا تبقى في ذاكرة العملية فقط.

توجد طبقة تخزين محلية أولية تعتمد SQLite وتحفظ:
- حالة كل مشروع مع رقم إصدار.
- بيانات صغيرة منظمة بمساحات أسماء.
- تشغيلات النظام ونقطة التوقف.
- مفاتيح منع تكرار التنفيذ.

رقم الإصدار يمنع عملية قديمة من الكتابة فوق حالة أحدث دون أن تنتبه.

مفتاح منع التكرار مهم خصوصاً عند انقطاع النظام بعد إرسال أمر خارجي: عند العودة لا يعيد نفس العمل تلقائياً قبل معرفة حالته.

هذه الطبقة خلف حد مستقل، لذلك يمكن لاحقاً استبدال SQLite بقاعدة مركزية دون تغيير منطق العقل.
