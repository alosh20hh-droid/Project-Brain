# طبقة النموذج

العقل لا يرتبط بشركة نموذج واحدة.

يوجد عقد موحد بين النظام وأي نموذج:
- رسائل موحدة.
- استجابة موحدة.
- استدعاءات أدوات موحدة.
- معلومات الاستهلاك اختيارية.

لهذا يمكن لاحقاً إضافة محول لأي مزود أو نموذج محلي بدون تغيير دورة المشروع.

النموذج يقترح القرار التالي فقط. لا ينفذ بنفسه، ولا يعتمد نجاح عمله بنفسه، ولا يتجاوز بوابة الموافقات.
