# دورة العقل

الدورة الأساسية لا تعتبر تقرير المنفذ حقيقة نهائية.

1. اقرأ حالة المشروع.
2. حدد أهم مجهول أو افتراض قد يوقف المشروع.
3. كوّن فرضية قابلة للاختبار.
4. اختر أرخص تجربة مفيدة.
5. حدد الدليل المطلوب قبل التنفيذ.
6. مرر طلباً محدود الصلاحيات إلى منفذ.
7. اجمع النتيجة والأدلة.
8. مررها إلى متحقق مستقل.
9. إذا رفضها المتحقق، لا تسجل المهمة كنجاح.
10. خزّن النتيجة والدروس ثم أعد التخطيط.

الهدف ليس تكرار المحاولة بلا نهاية؛ كل دورة يجب أن تقلل مجهولاً أو تنتج دليلاً جديداً.
