# الأدوات والتنفيذ

العقل لا يحصل على كل الأدوات تلقائياً.

لكل مهمة قائمة صريحة بالأدوات المسموحة. إذا حاول النموذج استدعاء أداة غير معروضة للمهمة، يرفض النظام التنفيذ مباشرة، وليس مجرد تحذير.

أنواع التنفيذ الحالية:
- داخلي: عمليات الذاكرة والحالة.
- بحث: جمع معلومات وأدلة.
- ملفات: قراءة أو إنتاج ملفات ضمن الصلاحية.
- متصفح: أعمال الويب المسموحة.
- خارجي: أنظمة تنفيذ مستقلة.

الموجه يختار منفذاً حسب نوع الأداة. يمكن لاحقاً استبدال أي منفذ بدون تغيير العقل.

قاعدة أمنية: الصلاحية تبدأ مغلقة. الأداة لا تعمل إلا إذا أضيفت صراحة إلى المهمة.
