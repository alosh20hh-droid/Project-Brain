# نموذج حالة المشروع

العقل لا يعتمد على ذاكرة المحادثة وحدها. الحالة الدائمة تحفظ خارج النموذج وتشمل:
- الأهداف وشروط النجاح.
- المجهولات حسب خطورتها على المشروع.
- الافتراضات والفرضيات والتجارب.
- المهام واعتمادياتها وحالتها.
- القرارات وأسبابها والأدلة المرتبطة بها.
- النتائج والدروس والفشل.
- الميزانية.
- نقاط الاستئناف والأحداث.

قاعدة: المجهول القادر على إسقاط المشروع يُختبر قبل التحسينات الثانوية.
