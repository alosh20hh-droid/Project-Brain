# Project Brain

مشروع مستقل لبناء عقل يدير المشاريع طويلة المدى بصورة منظمة وقابلة للتحقق.

## الفكرة
المالك يعطي هدفاً عاماً. النظام يحوله إلى فرضيات ومهام وتجارب، ينفذ الأعمال المسموحة عبر منفذين منفصلين، يجمع الأدلة، ثم يطلب من متحقق مستقل قبول النتيجة أو رفضها.

## مبادئ ثابتة
- المنفذ لا يصدق على عمله بنفسه.
- كل نجاح مهم يحتاج دليلاً.
- الدفع والعقود والعمليات الحساسة تحتاج موافقة المالك.
- حالة المشروع تحفظ خارج سياق النموذج.
- الفشل معلومة تستخدم لإعادة التخطيط.
- هذا المستودع مستقل ولا يعدل أي مستودع سابق.

## الحالة
المرحلة الأولى: هيكل مستقل قابل لتوصيل نموذج قوي وNous وPaperclip وUFO لاحقاً عبر محولات، بدون نسخ أو تعديل المستودعات الأصلية.
